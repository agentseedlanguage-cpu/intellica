APPLY
1. Upload `Intellica_CYB-3_Training_Academy_Checkpoint.zip` to the Codespaces repository.
2. From the repository root, run:
   unzip -o Intellica_CYB-3_Training_Academy_Checkpoint.zip -d .
3. Rebuild the public training pages:
   npm run training
4. Run validation:
   npm test
   npm run check
5. Review the resulting diff, then commit and push using your normal workflow.

BUILD PIPELINE
`npm run training` now rebuilds:
- the main Training page and homepage training block;
- the course catalogue and all public course/level landing pages;
- the Cybersecurity Academy's 14 public pages.

`npm run sync` also includes the Cybersecurity Academy builder. It additionally runs the course-player build and other site-generation steps.

PRODUCTION COURSE KEY — IMPORTANT
This checkpoint does not contain `.course-key`, `.env`, private lesson source, encrypted lesson payloads or learner data. Existing course-player pages, lesson IDs, access-code logic and learner progress have been left untouched.

Do not create or generate a replacement course key. Before running the full deployment/sync workflow, make sure the existing production key is available in the authorised Codespaces environment. The public training-page build (`npm run training`) and the test/check commands do not require that key.
