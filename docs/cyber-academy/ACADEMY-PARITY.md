# Architecture Academy and Cybersecurity Academy: parity review (CYB-2)

Basis: the architecture academy as shipped in checkpoint 36, and the cybersecurity academy in this checkpoint. Reviewed 25 November 2026.

## How each is built

| | Architecture Academy | Cybersecurity Academy |
|---|---|---|
| Hub page | `/training/architecture-academy/`, generated from `catalog.json` by `build-catalog.mjs` | `/training/cybersecurity/academy/`, generated by `tools/build-cyber-academy.mjs` (own namespace) |
| Level pages | Each level is its own online course page (`/training/<id>/`) | Level plan pages under `/training/cybersecurity/academy/level-N/` |
| Courses | Level 1 (14 lessons, US$149), Level 2 Mastering arc42 (US$129), Level 3 Quality, Decisions and Evaluation (20 lessons, US$199); Levels 4 to 6 planned | One online course (28 lessons) that serves all six levels; no separate level courses |
| Statuses | "Available now" or "Planned" | "N lessons live" per level, with a status line and the planned lessons |
| Training page | Architecture track with a link to the hub | Both academies now have a card on the training page; the cyber course page links back to its academy |

## Who is ahead, by feature

| Feature | Ahead | Notes |
|---|---|---|
| Shipped, purchasable product per level | Architecture | Three levels are separate courses with prices and access. The cyber course is one course across six levels |
| Practice bank | Architecture | 124 mock items in three papers, plus 70 lesson questions (194). Cyber has 84 lesson questions plus 48 placement items (132) |
| Level pages with modules, evidence, assessment, external mapping | Cybersecurity | Architecture levels are course pages without a level-by-level evidence and assessment model |
| Pathways by role | Cybersecurity | Six pathways |
| Source register with versions and review dates | Cybersecurity | Architecture lists sources per lesson but has no academy-level register |
| Independence and credential policy page | Cybersecurity | Architecture covers this in its "What the academy is not" section |
| Gap register and roadmap | Cybersecurity | Public, with exit gates |
| Placement check | Cybersecurity | 48 questions, scored in the browser. Architecture has none |
| Honest "what the academy is not" section | Both | Cyber hub now matches the architecture wording pattern |

## What changed in CYB-2 to bring them level
1. The cyber hub now uses the same components as the architecture hub: the level path strip, `cat-card` level cards, "How the academy works" and "What the academy is not", and the "Enter access code" link.
2. The training page has an Academies block with both academies, and the featured cybersecurity course links to its academy.
3. The cybersecurity course page links to its academy.

## Suggested upgrades for the Architecture Academy (for the architecture chat to decide)
These live in the architecture chat's files, so they are not applied here.
1. **Pathways by role:** a short page (builder, architect, reviewer, leader) built from the same data pattern.
2. **Academy source register:** one dated, version-pinned page (iSAQB CPSA-F curriculum 2025.1 and the 2027 release candidate, arc42, ISO/IEC 25010, Q42 and the ADR and ATAM sources already read in earlier checkpoints).
3. **Placement check:** `tools/cyber-academy/questions.mjs` and `placement.mjs` are data-driven. An architecture version needs only its own 6 x 8 question file and a builder call.
4. **Level pages with evidence:** for the three planned levels, publish the same module, evidence and assessment outline the cyber levels have, so "planned" means something specific.

## Decision for the owner
The cyber academy sells one course covering six levels, while the architecture academy sells each level separately. Either keep one cyber course and treat levels as paths (current state), or split the course into level courses later. Splitting needs content per level and is a product decision, not a build task.
